## Lessons Learned

1. **When a value is legitimately duplicated across two files for structural reasons (e.g., a self-contained published artifact vs. a separate app reading shared config), don't trust a comment describing the intended invariant ("matches what's tuned elsewhere") — verify the actual numbers against each other before shipping.** Comments describing an invariant are not the same as the invariant being enforced.

2. **A script-injection or automation-tool timeout against a page is not evidence the page's content is broken — it can equally mean the tool cannot operate in that page's security context** (sandboxed cross-origin iframe, strict CSP, extension permissions). Before concluding "I broke this," cross-check with an independent access method (a proper content fetch, not a script-injecting one) and check for origin-matched console errors specifically, not just "any console output."

3. **When a user reports a failure you cannot reproduce because it happens in an environment you can't see (their browser, their login session, a link opened by someone else), ask a short, targeted, multiple-choice-shaped question early** rather than spending several tool calls trying to reverse-engineer the symptom blind. The fastest path to root cause is often the person who can actually see the screen.
